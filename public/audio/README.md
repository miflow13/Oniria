# DEV Library audio

The DEV Library uses the SolarFLEX track **Ambient - Ambient Music** as its
continuous ambience.

Runtime path:

`/audio/solarflex-ambient-ambient-music-569592.mp3`

Repository path:

`public/audio/solarflex-ambient-ambient-music-569592.mp3`

The track is served locally by Next.js and loops in the browser. There is no
runtime dependency on Pixabay, so local development and deployed builds do not
depend on an external metadata request.

The previous generated lofi composition and continuous noise/drone layer have
been removed. Footsteps and shelf interaction sounds remain.
